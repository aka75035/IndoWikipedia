# IndoWiki 🇮🇳

An open-source encyclopedia inspired by Wikipedia, built from an Indian perspective.

## 📖 About

IndoWiki aims to provide accurate, well-structured, and reliable information about India, including its history, culture, geography, science, literature, languages, heritage, and notable personalities.

The project is community-driven and welcomes contributions from developers, researchers, and writers.

## ✨ Features

* 📚 Read and search articles
* ✍️ Create and edit articles
* 🔍 Powerful search
* 👤 User authentication
* 📝 Revision history
* 🌐 Multi-language support *(Planned)*
* 🤖 AI-assisted writing *(Planned)*
